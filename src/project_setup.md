# Project Setup

## Getting Started
If you have already created a stage beforehand, it’s best that you create another Blender file for baking in case it corrupts or interferes with your original model. If you are starting with a model that hasn’t been imported to Smash Ultimate yet, grab all of the model files and go to File > Import > Collada* (.dae) or FBX(.fbx).
