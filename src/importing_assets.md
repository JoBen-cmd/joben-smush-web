# Importing Assets
Since we are using Smash Ultimate’s Blender plugin, importing the assets and seeing if everything looks fine should be very easy. Here’s what you’ll need to do:

In the layout tab, click Ultimate and in the Model Exporter section, select an armature. You won’t need to select the vanilla .nusktb since it's not a character mod so click **“Export Model Files Anyways…”** and choose your desired location. You won’t need to make any further export changes unless desired.

After that everything should be good to go. You can go check if everything is working by opening the model files in SSBH editor and if that's good, you should be ready. Just make sure that your config.json (if you are using file/dir addition) and directory folder locations are in the right spot and it should load as intended once you play the stage in-game.
